> 状态：`todo`　依赖：M09　验收：`apps/web/index.html` 存在

## 目标
HTML 单页（零构建，原生 JS + ECharts CDN 可选）：
- **对话台**：宽泛提问 → 展示结构化评估报告（总分、维度雷达图、证据引用、缺口清单）；
- **看板**：列表选择教师/模板，查看维度得分、趋势（多周期对比）。
