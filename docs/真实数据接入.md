# 真实数据接入说明

工作区压缩包 `教育数字化数据库.zip` 是**学校数字化评估**库（不是单教师人事库）。已用其中 CSV 接入评估管线；两份巨型 SQL dump 与 CSV 同源，不必再导入。

## 数据规模（已导入 SQLite）

| 文件 | 规模 |
|---|---|
| `data/real/questions.csv` | 83 题，6 个一级维度 |
| `data/real/schools.csv` | 374,887 条学校×年份（2020–2023） |
| `data/real/school_answers_1..5.csv` | 1,509,896 条归一化答案 |
| `data/real/education_digitization.sqlite` | 约 121 MB 检索库 |

一级维度：数字资源 / 教育教学 / 数字素养 / 基础设施 / 教育治理 / 保障机制。

## 重新导入

```bash
python scripts/import_real_data.py          # CSV → sqlite
python scripts/build_real_template.py       # questions.csv → YAML 模板
python scripts/school_engine.py             # 试跑一所学校
```

## 提问方式（对话 / API）

```
长沙县成绩小学 2020 数字化水平怎么样？
```

```bash
python -c "import apps.api.main as m; print(m.chat('长沙县成绩小学 2020 数字化水平怎么样？')['markdown'])"
```

REST（fastapi 已装时）：

- `GET /api/v1/schools?q=成绩小学&year=2020`
- `GET /api/v1/schools/{id}/report`
- `POST /api/v1/chat`  `{"question":"长沙县成绩小学 2020 数字化水平怎么样？"}`

口径：`normalized_value × 100` → 维度等权均值 → 一级维度按模板权重加权。无答案的题记入缺口，不编造分数。
