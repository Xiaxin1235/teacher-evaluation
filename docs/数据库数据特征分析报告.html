② Q4 归一化口径被污染 🔴

Q4 的 normalized_value 使用了被异常值污染的极大值 1009 作分母：99.01% 的正常值（0–100）归一化后全部落在 [0, 0.099]，得分被系统性压缩约 10 倍，跨题不可比，直接影响综合评分。
其他题目分母校验：Q1=21、Q3=11、Q5=3 与实测最大值一致 ✅；但 Q6–Q83 推断分母普遍大于实测最大值（Q6 分母 5/最大 4，Q7 分母 13/最大 10），满分口径与实测不符。

6.1 分析使用建议

  1. 横向对比：仅使用 Q2、Q4（四年全量有效）；Q1 限 2020–2022；Q3 限 2020–2021。
  2. 纵向趋势：仅 7,706 所有 4 年数据，做趋势分析时需先按学校过滤并说明样本偏差。
  3. 权重体系：当前三级权重恒为 1，若需差异化评估必须先设定权重再重算，否则「维度得分」实为题目均分。
  4. 规模相关指标（生均、班额等）：只能在 2022–2023 年样本上计算，且需先剔除极端值。
  5. 缺失值处理：所有缺失以空字符串表示，ETL 时统一转换为 NULL 更利于后续处理。
口径说明：记录数与聚合统计均基于 SQLite 全量扫描（规模字段分位数基于 165,607 条非空样本）·「有效作答」判定为 value <> 0 · 归一化分母由 value / normalized_value 反推 · 生成时间 2026-09-08
