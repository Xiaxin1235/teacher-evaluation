# 需求确认单（一页纸）

> 用途：业务方（教务处 / 教研组 / 人事）与技术团队在 1~2 次工作坊内敲定关键决策。
> 每个决策项旁边有 `建议默认值`（技术团队建议），可修改。全部确认后签字，作为 P0 启动输入。
